# ER-диаграмма

Во вкладке **ER-диаграмма** страницы подключения отображаются таблицы/коллекции, поля и связи
внешних ключей из последней синхронизированной версии каталога. Диаграмма не делает запросов к
внешней БД при открытии: она использует уже сохранённые метаданные.

## Связи

PostgreSQL и MySQL connector сохраняют foreign key вместе с исходными и целевыми колонками.
На canvas такая связь показана стрелкой от дочерней таблицы к родительской. Для MongoDB связей
не строится, поскольку модель документов не содержит внешних ключей.

## Раскладка

У сохранённого подключения его владелец может перемещать карточки за заголовок. Раскладка
сохраняется в `localStorage` конкретного браузера и конкретной версии метаданных. Кнопка
«Сбросить» возвращает автоматическую сетку.

JSON-снимки открываются в режиме просмотра: их расположение не меняется. Изменение canvas не
выполняет DDL, не изменяет внешнюю БД и не требует расширенных прав у её пользователя.
