# ER-диаграмма

ER-диаграмма открывается отдельным маршрутом `/er`, доступным из боковой навигации и кнопки
**ER** на странице базы. В верхнем списке выберите сохранённое подключение либо JSON-снимок.

Canvas отображает таблицы/коллекции, поля и связи внешних ключей из последней
синхронизированной версии каталога. Открытие не создаёт нового соединения с внешней БД.

## Связи

PostgreSQL и MySQL connector сохраняют foreign key вместе с исходными и целевыми колонками.
На canvas связь показана стрелкой от дочерней таблицы к родительской. Для MongoDB связи не
строятся, поскольку модель документов не содержит внешних ключей.

## Раскладка

У сохранённого подключения его владелец может перемещать карточки за заголовок. Раскладка
сохраняется в `localStorage` конкретного браузера и конкретной версии метаданных. Кнопка
«Сбросить» возвращает автоматическую сетку.

JSON-снимки открываются в режиме просмотра. Изменение canvas не выполняет DDL, не изменяет
внешнюю БД и не требует расширенных прав у её пользователя.
